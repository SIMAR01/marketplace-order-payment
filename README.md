# Marketplace Order & Payment Management

## Project Overview
This repository contains a full-stack marketplace application being developed as a technical assessment. The application will manage order processing, client workflows, and payments under a Dockerized local development stack.

## Current Status
The initial backend and frontend project structure and TypeScript scaffolding have been created. No business functionality (APIs, authentication, database schemas, checkout shopping cart, or payment webhook logic) has been implemented at this stage.

## Tech Stack
* **Node.js** (Express, TypeScript, Docker)
* **React** (Vite, TypeScript, Tailwind CSS, Redux Toolkit, React Router DOM)
* **MongoDB**

## Frontend
Technology:
- React
- Vite
- TypeScript
- Redux Toolkit
